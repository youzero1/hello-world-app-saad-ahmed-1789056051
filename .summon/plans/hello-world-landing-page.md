## Goal
A single landing page at the root URL (`/`) that displays a centered "Hello World" greeting with clean, modern typography, a subtle background, and a responsive layout. No backend, no auth, no data fetching.

## Current-state notes
- The project is currently empty: `listProjectStructure` returned no files, and `package.json` and `src/main.tsx` do not exist.
- Therefore the base app shell, router setup, route files, and global stylesheet all need to be created from scratch.
- `src/routeTree.gen.ts` is generated by the router plugin — never author or edit it by hand.

## Steps

1. **Project scaffolding — `package.json`**
   Declare an ESM React + TypeScript app with dependencies for React, TanStack Router (router + route plugin), Vite, the Tailwind CSS v4 Vite plugin, and TypeScript. Add `dev`, `build`, and `preview` scripts.
   *Outcome:* `npm install` resolves and dev/build scripts exist.

2. **Vite config — `vite.config.ts`**
   Register the React plugin, the TanStack Router file-based routing plugin (pointing at `src/routes`), and the Tailwind CSS v4 Vite plugin. Configure the `@/` alias to resolve to `src/`.
   *Outcome:* dev server starts, routes are auto-discovered, Tailwind classes compile, `@/` imports resolve.

3. **TypeScript config — `tsconfig.json`**
   Strict TypeScript for a bundler-based React app, JSX set for React, and the `@/*` → `src/*` path mapping to mirror the Vite alias.
   *Outcome:* editor and build both resolve `@/` imports with no type errors.

4. **HTML entry — `index.html`**
   Root document with a mount node, page title ("Hello World"), viewport meta tag for mobile responsiveness, and a module script pointing at `src/main.tsx`.
   *Outcome:* app mounts in the browser; mobile scaling behaves correctly.

5. **Global styles — `src/styles/global.css`**
   The file must start with exactly `@import "tailwindcss";`. Optionally add a small base layer for full-height html/body and default antialiased text. No component-specific CSS here.
   *Outcome:* Tailwind utilities available app-wide from one stylesheet.

6. **App entry — `src/main.tsx`**
   Import `src/styles/global.css` once, create the router from the generated route tree, and render the router provider into the root node inside React StrictMode.
   *Outcome:* the app boots and routing is active.

7. **App shell route — `src/routes/__root.tsx`**
   Define the root route with a minimal layout wrapper (full-height container, subtle background gradient/tint, base text color) rendering an `<Outlet />`. No navigation bar needed for a single-page app.
   *Outcome:* every route renders inside a consistent, styled shell.

8. **Landing route — `src/routes/index.tsx`**
   Define the `/` route. Render a `Greeting` component centered both vertically and horizontally using Tailwind flex/grid utilities on a min-height-screen container with responsive padding.
   *Outcome:* visiting `/` shows the centered greeting.

9. **Greeting component — `src/components/Greeting.tsx`**
   Presentational component with an `<h1>` reading "Hello World" plus an optional short subheading line. Use responsive type scale (smaller on mobile, larger on desktop), tight tracking, bold weight, and a muted color for the subheading. Accept an optional `name`/`message` prop with a default so the text stays configurable but requires no wiring.
   *Outcome:* reusable, readable greeting block that scales cleanly across breakpoints.

10. **Shared types (only if needed) — `src/types/`**
    If the `Greeting` props grow beyond a single string, extract the prop type here; otherwise skip this step.
    *Outcome:* no unnecessary files added.
